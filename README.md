# Trentino Tourism Knowledge Graph

This repository contains the material produced for the Knowledge Graph project developed according to the iTelos methodology.

## Project Scope
The project focuses on the integration of tourism-related datasets for the Trentino region, including museums, natural attractions, hotels, and their spatial organization at the city level.

## Repository Structure

- Documentation/: Final project report and source files
- Phase 1 - Purpose Definition/: Purpose definition artifacts and ER diagram
- Phase 2 - Information Gathering/: Original datasets
- Phase 3 - Language Definition/: Language Teleontology (LTLO)
- Phase 4 - Knowledge Definition/: Knowledge Teleontology and Teleology
- Phase 5 - Entity Definition/: KARMA mappings, RDF graphs, GraphDB queries and visualizations
- Evaluation/: Evaluation queries and metrics
- Metadata/: Metadata definitions for datasets, ontologies, and the final KG

## Tools Used
- Protégé (ontology modeling)
- KARMA (entity mapping and RDF generation)
- GraphDB (storage, visualization, and querying)
